# JavaScript 최종과제 — Calculator

오즈코딩스쿨 JavaScript 심화 최종과제입니다.  
기존 계산기에 계산 기록 저장과 `localStorage` 연동을 추가했습니다.

## 실행 방법

ES 모듈(`type="module"`)은 `file://`에서 동작하지 않습니다.  
VS Code Live Server로 `index.html`을 열어 주세요.

1. 저장소를 클론합니다.
2. VS Code에서 폴더를 역니다.
3. Live Server로 `index.html`을 실행합니다.

## 구현 범위

필수 과제만 구현했습니다.

| 파일 | 구현 |
|------|------|
| `js/calculator.js` | 과제 1~4 (`appendNumber`, `appendOperator`, `calculate`, `deleteLast`) |
| `js/history.js` | 과제 5~7 (`loadHistory`, `saveHistory`, `addHistory`) |

도전 과제(`%` 연산, 기록 개별 삭제, 기록 클릭 불러오기)는 구현하지 않았습니다.
